## 🚀 About The Project
This repository hosts the official web portal and landing page for **Nexus Web Development**, the digital and engineering arm of the **Nexus Research, Space, and Technology Club** at **Manipal University Jaipur (MUJ)**.

### Objectives
- Showcase deep tech, aerospace, astronomy, and robotics research conducted at MUJ.
- Provide interactive 3D visualizations, data dashboards, and mission telemetry.
- Serve as the nexus for tech events, workshops, hackathons, and recruitments.
